# Advanced Java & Servlet Applications

This repository contains my practical work and projects developed while learning **Advanced Java, JDBC, Servlets, and JSP**.

The projects demonstrate Java web application development, database connectivity, servlet-based request handling, and MVC architecture.

## Technologies Used

- **Programming Language:** Java
- **Web Technologies:** HTML, CSS
- **Java Web:** Servlets, JSP
- **Database:** Oracle Database / JDBC
- **Server:** Apache Tomcat
- **IDE:** Eclipse IDE
- **Version Control:** Git & GitHub

## How to Run the Projects

1. Install JDK and Eclipse IDE.
2. Install Apache Tomcat Server.
3. Clone this repository:

   ```bash
   git clone https://github.com/sahilsangle24/AdvJava-Servlet-Applications.git
   ```

4. Open Eclipse IDE.
5. Select **File → Import → Existing Projects into Workspace**.
6. Choose the required project folder.
7. Configure Apache Tomcat in Eclipse.
8. Add the required JDBC driver if the project uses database connectivity.
9. Run the project on the Tomcat server.
